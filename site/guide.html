User guide

Set up a sorting session and return to it later.

Start the web app

Prepare the browser

Use desktop Chrome or Edge for folder access. When the app shows Offline ready, bookmark the app page and reopen that address to work offline. For a portable copy, extract the offline ZIP and open Data Sorter.html.

Sort a folder

  1. Choose the input folder and a destination for sorted files. Data Sorter scans the input and its subfolders.
  2. Select Copy to retain the source files or Move to relocate them. Move mode requires write access to the input folder.
  3. Add categories and assign a shortcut to each. Start sorting and use the category buttons or shortcuts to make decisions.

Use the arrow keys to navigate without assigning a category. Use Undecided only to hide sorted files. Use Ctrl + Z or Command + Z to undo the last decision.

Review previews

The app retains the zoom level between files. Use the slider or a zoom gesture, scroll through documents and drag to pan when a preview extends beyond the viewing area. DICOM shows the first frame. DOCX preview shows extracted text.

Resume a session

Export data_sorter_results.csv to the output folder. To resume, import the CSV and select the current input and output folders. The app restores decisions and position. Undo history starts with the next decision.
