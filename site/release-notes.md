Data Sorter previews and sorts local files in the browser. The web app supports JPEG, PNG, DICOM, PDF, DOCX, TXT and CSV. It offers copy and move modes, category shortcuts, undo and CSV session export and restore.

To use the offline download, extract `data-sorter-offline.zip` and open `Data Sorter.html` in desktop Chrome or Edge. The ZIP includes the licence and third-party notices. The checksum file can be used to verify the download.
