Software checks

Review the tests for sorting, previews and the offline cache.

What's tested

  • Session CSV parsing, folder scans, copy and move, undo and recovery after a failed write.
  • PDF zoom and pan, document and image previews, keyboard shortcuts and file-list scrolling.
  • Offline reopening after the original server stops and consistency between the downloadable and hosted app.

Evidence and reproducibility

Automated checks use synthetic files. The browser tests supply test folder handles in place of the operating system's folder picker. The report describes the tested formats and the limits of coverage.
